# Sample Audio Directory

This directory contains test audio files for validating the AvianAI India bird sound identification system.

## Indian Bird Samples (samples/indian_birds/)

- 01_indian_peafowl.wav: Indian Peafowl (Pavo cristatus)
- 02_indian_roller.wav: Indian Roller (Coracias benghalensis)
- 03_common_kingfisher.wav: Common Kingfisher (Alcedo atthis)
- 04_red_vented_bulbul.wav: Red-vented Bulbul (Pycnonotus cafer)
- 05_oriental_magpie_robin.wav: Oriental Magpie-Robin (Copsychus saularis)

## Synthetic Noise (samples/test_noise.wav)
- Used to test and verify the low-confidence detection threshold ("No confident bird detected").
